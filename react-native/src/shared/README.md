# Gedeelde bouwstenen

Deze map bevat herbruikbare interfacecomponenten, themawaarden, formulieren en animatiehulpmiddelen. Functiespecifieke onderdelen blijven bij hun eigen feature. Importeer de algemene componenten via `shared/components` en kleuren via `shared/theme`.

Tekst met gegevens van gebruikers wordt letterlijk getoond. Vertaal interfacekopij expliciet met `useI18n().t` of de vertaaloptie van de tekstcomponent; zie [components](./components/README.md). Houd volledige, bestaande vertaalde zinnen intact.
