# Oefenen en statistieken

`screens` bevat doelen, voortgang, focus, checklist en het statistiekenscherm. `components/ReadingStatisticsOverview.tsx` wordt ook op het dashboard gebruikt; `StatisticsHistory.tsx` en `StatisticsSurface.tsx` ondersteunen de presentatie. `providers/FocusProvider.tsx` bewaart de actieve focussessie. Berekeningen staan onder meer in `domain/statistics.ts`, `goals.ts` en `hifz.ts`.
