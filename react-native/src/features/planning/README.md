# Planning

`screens/PlanningScreen.tsx` toont de agenda en `ReadingPlanScreen.tsx` het leesplan. `components/ReadingPlanHomeCard.tsx` is het herbruikbare dashboardonderdeel; `ReadingJourneyPanel.tsx` en `AgendaCalendar.tsx` blijven planning-specifiek. `hooks/useReadingPlan.ts` coördineert planacties; regels staan in `domain` en herinneringen in `services/notifications`.
