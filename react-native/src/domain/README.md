# Domeinregels

Deze modules berekenen appgedrag zonder schermen of I/O. Voorbeelden: `goals.ts` berekent doelen, `statistics.ts` groepeert leesgeschiedenis en `mushafReading.ts` bepaalt leesbereiken. Geef gegevens en relevante datums expliciet mee; render geen UI en roep geen netwerk of opslag aan.
