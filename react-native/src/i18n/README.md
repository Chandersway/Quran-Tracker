# Interfacevertalingen

`index.ts` biedt `useI18n`, `translate` en formattering van volledige bronzinnen. `source-catalog.json` bewaart samengestelde kopij en herkomst; `source-aliases.json` en `screen-source-keys.json` koppelen bestaande teksten aan sleutels. Vertaal interfacekopij expliciet, behoud volledige zinnen en toon gebruikersinhoud letterlijk. Koranvertalingen zelf staan in `content`.
