# Quran Tracker design system

Quran Tracker is an Arabic-led Quran reading and practice app. Its visual world takes the discipline of a reading index and contemporary Arabic typography as its starting point: deep cypress, warm chalk and a restrained terracotta action. Preserve the original app name and symbol. Manuscript and geometric details should explain navigation or frame the actual printed book. The generated references in `design-preview/concepts/` are visual exploration, not sources of text or user data.

The app is an Operate and Read surface. Native navigation, exact Quran text, accurate references and accessible Arabic take precedence over ornament. Use Noto Kufi Arabic for Arabic interface text, DM Sans for Latin interface text, and Amiri for the Quran text reader. The selectable printed Hafs page uses its original QPC font and prescribed line boundaries; replacing that font is not a cosmetic change. Honor text scaling and keep Quran text independently adjustable. Arabic screens use right-to-left reading alignment and navigation order; verify controls and mixed-script content on both platforms.

The primary light surface is chalk (`#F3EFE4`); cypress (`#183B30`) anchors the reading surface and navigation, with warm terracotta (`#A95E40`) for a decisive action or selected marker. Light and night palettes are defined in `src/ui/theme.tsx` and must maintain readable contrast. Cards use a single surface, restrained edges and no nesting. Reserve the dark reading panel for a real saved position; never draw a decorative progress ring that implies unrecorded activity.

The bottom dock is a continuous cypress baseline with a small terracotta active rule. Its primary destinations are Statistics, Mushaf and Groups, followed by More. Statistics opens the dashboard, daily goal and independent reading-plan rings, the three original reading distributions, exact history, Hizb overview and independent Hifz assessments. Mushaf resumes the chosen book presentation at a verified reference: selectable Hafs by default for Hafs-family editions, or an explicitly chosen original scan/PDF, with Warsh retaining its edition; the text reader is available as a study tool. Groups opens the user's groups and each group's own feed. More exposes Surah, Hizb, Juz, Agenda, notes, focus, checklist, library and settings. Labels come from the original Kotlin catalog, with new overflow and accessibility controls explicitly identified as new UI copy. Keep all original destinations reachable, use labeled controls, preserve 48-point touch targets and honor safe-area insets.

Use the original Kotlin app's curated text through source catalog keys; format complete sentences and preserve Quran text. Maintain content, reading position, data scope and import/export behavior. Show actual recorded progress, an immediate continue action and original tools. Preserve useful empty, loading, offline and recovery states. Opening or scrolling a Mushaf never creates reading history; explicit registration records a verified page range, while unmapped editions offer the existing manual check-in.

Native sheets and rows carry secondary tasks; motion should clarify a transition and respect reduced-motion preferences. Validate phone and tablet layouts, large type, screen readers, RTL, dark mode and shipped Android/iOS builds. The selected concept is a directional reference: its leaf, invented radial graphic, generated copy and five illustrative labels are not implementation requirements.
